🐾 Neko-Sensei's erweiterter Spickzettel

1. Partikel-Übersicht:
• は (wa) ➔ Thema des Satzes (Worum geht es?)
• が (ga) ➔ Subjekt / Fokus (Wer/was tut es? Neuer Info-Fokus)
• を (o) ➔ Akkusativ / direktes Objekt (Was wird gegessen/gemacht?)
• に (ni) ➔ Ziel, Richtung oder Zeitpunkt (Wohin? Wann?)
• へ (e) ➔ Richtung / zu (in Richtung von...)
• の (no) ➔ Genitiv / Zugehörigkeit (z.B. mein Buch)

2. Adjektiv-Regeln (Neu!):
• i-Adjektive: Enden auf -i (z.B. たかい / takai = teuer/hoch). Verneinung: `-kunai` (takakunai). Vergangenheit: `-katta` (takakatta).
• na-Adjektive: Verhaltensweise wie Nomen (z.B. きれい / kirei = schön/sauber). Vor Nomen braucht es ein **な (na)** (z.B. kirei na kaban). Verneinung mit `ja arimasen`.

3. Te-Form Spezial:
• Verknüpfung: A-te, B (und dann...)
• Gerade dabei sein: [Te-Form] + います (imasu)

💡 Tipp: Klammern für Lesehilfe nutzen: Wort(lesehilfe).
