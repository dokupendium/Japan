# Japan – Japanisch-Lern-App

Ein kleines, browserbasiertes Lernprogramm zum Vokabeln und Grammatik für Japanisch. Die App ist als einzelne HTML-Datei umgesetzt und läuft ohne Backend oder Installation.

## Überblick

Das Projekt enthält:

- `Lerntool.html` – die komplette Lern-App mit Karten, Quiz, Grammatik-Trainings und Kana-Übungen
- `index.html` – Weiterleitung auf die Lern-App

## Funktionen

- Lernkarten mit Japanisch ⇄ Deutsch
- Wiederholungsmodus und Statistik
- Quiz mit Multiple-Choice und Freitext
- Verb- und Zeitformen-Übungen
- Satzbau- und Grammatik-Training
- Hiragana/Katakana-Übungen
- Vokabelliste verwalten
- Daten als Backup exportieren

## So nutzt du das Projekt

1. Klone oder lade das Repository herunter.
2. Öffne `Lerntool.html` in deinem Browser.
3. Starte direkt mit dem Lernen.

Alternativ öffnet `index.html` automatisch auf die Lern-App weiter.

## Beispiel

Die App nutzt lokale Browser-Speicher (`localStorage`), um:

- Vokabeln zu speichern
- Lernfortschritt zu verfolgen
- Statistiken zu verwalten

Dadurch funktioniert die Anwendung komplett clientseitig – ohne Server oder Datenbank.
